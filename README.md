# Kotlin Full Course – Cheezy Code

A complete Kotlin learning repository containing all the code, examples, and practice programs that I created while following the **Cheezy Code Full Kotlin Course**.

This repository covers Kotlin from beginner to intermediate level with hands-on examples and mini practice programs. Every topic is organized into separate files to make learning easier and to serve as a quick reference in the future.

---

## 📚 Topics Covered

### Kotlin Basics
- Variables (`val` & `var`)
- Data Types
- Type Conversion
- Operators
- User Input
- Strings

### Control Flow
- if / else
- when Expression
- for Loop
- while Loop
- do-while Loop
- break & continue

### Functions
- Function Declaration
- Parameters
- Return Types
- Default Arguments
- Named Arguments
- Single Expression Functions

### Object-Oriented Programming
- Classes & Objects
- Constructors
- Properties
- Getters & Setters
- Inheritance
- Overriding
- Polymorphism
- Abstract Classes
- Interfaces
- Data Classes
- Object Declaration (Singleton)
- Companion Object

### Kotlin Features
- Null Safety
- Safe Call Operator
- Elvis Operator
- Smart Casting
- Type Checking
- Lateinit
- Lazy Initialization

### Collections
- Arrays
- List
- MutableList
- Set
- Map
- MutableMap

### Advanced Kotlin
- Higher Order Functions
- Lambda Expressions
- Scope Functions
  - let
  - apply
  - also
  - run
  - with
- Extension Functions

1. Clone the repository

```bash

```

2. Open the project in **Android Studio** or **IntelliJ IDEA**.

3. Run any Kotlin file to explore the examples.
